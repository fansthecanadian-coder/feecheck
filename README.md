# FeeCheck

FeeCheck is a zero-dependency marketplace profit calculator.

## What it does
Enter sale price, item cost, shipping charged, shipping cost, percentage marketplace fee, and fixed fee. FeeCheck calculates customer total, estimated marketplace fees, estimated profit, and profit margin.

## Deploy for free
This repo is designed to work on GitHub Pages with no build step.

In GitHub: Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.

Your site should then be available at:
`https://fansthecanadian-coder.github.io/feecheck/`
